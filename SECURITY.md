# Security Policy

## Supported Versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a Vulnerability

If you discover a security issue, please report it by opening an issue:

https://github.com/kafkade/flightdeck/issues

When reporting, include:

1. A clear description of the vulnerability
2. Reproduction steps or proof of concept
3. Impact assessment (what an attacker can do)
4. Suggested remediation (if available)

Please avoid publishing exploit details before a fix is available.
